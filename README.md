# DentNotes

Σημειωματάριο ασθενών οδοντιάτρου (PWA) με καρτέλες ασθενών, ιατρικό ιστορικό, ακτινογραφίες και ημερολόγιο επισκέψεων.

**Εφαρμογή:** https://tzirasg.github.io/dentnotes/

Εγκατάσταση στο iPhone: άνοιξε τον σύνδεσμο στο Safari → Κοινοποίηση → «Προσθήκη στην οθόνη Αφετηρίας».

Όλα τα δεδομένα ασθενών αποθηκεύονται **μόνο τοπικά στη συσκευή** (IndexedDB) — τίποτα δεν αποστέλλεται σε server.
